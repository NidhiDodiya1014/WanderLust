# 🌍 WanderLust

WanderLust is a full-stack web application that allows users to explore, create, and review campground listings from all over the world. It's inspired by platforms like Yelp and built using Node.js, Express, MongoDB, and EJS.

![WanderLust Banner](https://via.placeholder.com/1200x400?text=WanderLust+Campgrounds)

## 🚀 Features

- 🧭 Browse and search for campgrounds
- 📝 Create, update, and delete campgrounds (CRUD)
- 📸 Upload campground images via Cloudinary
- 💬 Comment and review system
- 🔐 User authentication and authorization with Passport.js
- 📍 Geolocation support with Mapbox
- 🧼 Server-side input validation and sanitization
- 🎨 Responsive UI using Bootstrap 5
